# First two hours on real Everon (#4953, X-6 hours 0 to 2): the one reliable new-player route.
# Quiz and form R-89, hostel, the clerk's welcome, the starter car, apples, the juice press, the
# market trader, the F2 file's "Errands done 5 / 5", and the car put back in the garage so the next
# fresh character finds a free pad. It replaces arrival-island.txt and island-first-hour.txt (retired;
# their later steps are not part of hours 0 to 2).
#
#   node agent-box/session.mjs up --mission island --profile full --clients 2 --wait
#   node agent-box/harness.mjs --client 1 flow playtest-030-first-two-hours
#   node agent-box/session.mjs down
#
# The client must be a fresh account: the rules quiz and form R-89 are its first screens, and the
# step 0a asserts are the arrival values (cash $100, bank $2,000). A second run on the same account
# fails step 0a on purpose; use another client (`session.mjs join <n>`) for another fresh character.
#
# The flow judges itself (agent-box/flow-asserts.mjs): `step` opens a judged step, a failed line or a
# failed `expect` fails it, and the run ends with a PASS/FAIL table (exit 1 on any failed step).
#
# The clerk talk is driven the way a player does it, and a dropped keypress cannot pick "bye":
#   - `dialogue-choose <node> <digit> <next>` (harness.mjs) waits for the reply list on <node>, presses
#     LF_Keypad<digit> (1 is the first reply; the Goodbye key 0 is refused), and checks the scene moved on to
#     <next>. Harness keys are dropped on a loaded client (a MenuDown/MenuUp/MenuSelect triple once picked "bye"):
#     after two dropped presses it answers with `dialogue pick <digit - 1>`, the scene's own pick, and the
#     flow log says "via pick (keys dropped)". A pick that lands on any other node fails the step.

step 0a Hour 0: wake in the hostel with the arrival money and no papers
expect cash =100
expect bank =2000

step 0b Hour 0: the clerk registers you (ID card, welcome pack, $100)
stand Fit_saint_philippe_arrival_town_hall_clerk e2
wait 1500
shot ui p_0b_clerk_waypoint
use LF_QuestAction Fit_saint_philippe_arrival_town_hall_clerk
dialogue-wait choosing greet
shot ui p_0b_clerk_greets
# greet: reply 1 is "I'm new here" (reply 0 would be Goodbye). Each dialogue-choose waits for the reply list
# on that node, presses the digit, and fails unless the scene is on the node named last afterwards.
dialogue-choose greet 1 welcome_papers
dialogue-choose welcome_papers 1 welcome_room
dialogue-choose welcome_room 1 welcome_town
# welcome_town: "Ready" hands in the register quest (ID card, $100, the starter car to the garage).
dialogue-choose welcome_town 1 menu
shot ui p_0b_welcome_pack
input MenuBack
dialogue-wait closed
wait 3000
expect cash =200
expect state idcard set
expect state quests ~arrival_register

# The garage has two pads: a car left out would block the next fresh character's starter car on the same
# session (`spawn refused: no free pad for roadmap-garage`, #LF-Garage_PadBusy). `send park` stands in for
# driving the car to the garage; the store action then frees the pad.
step 2d Hour 2: drive the starter car back and store it in the garage

wait 2000
