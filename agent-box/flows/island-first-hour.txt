# Island first hour (#2935, the Friday go/no-go gate): a newcomer's first hour on Saint Philippe,
# real Everon (MainWorld), steps 1 to 10 of C:\LF\lead\weekend-everon.md "The first hour".
# The manual twin for the live 0grind smoke is docs/playtest/island-first-hour.md.
#
#   node agent-box/session.mjs up --mission island --clients 1 --roster 1 --profile full --wait
# (--roster 1 lets client 1 clock in as police; `--admin-client` is refused off the playtest mission.)
# A step passes when its stand/use lines say ok AND the `state` line after it moved (cash, bank, job,
# duty); the harness cannot assert that, so read the state lines. The 2026-11-18 run on main is in
# docs/playtest/island-first-hour.md "Flow status".
#   node agent-box/harness.mjs --client 1 flow island-first-hour
#   node agent-box/session.mjs down
#
# Each step opens with a `shot ui island_<n>_<step>` so the output reads step by step; the step's
# `use`/`stand` lines that follow say ok or error. The flow does not stop on a failed line, so one
# run reports every step. Fresh profile: form R-89 is the first screen.
#
# Entities are named in the fitted island layers (addons/LF_Everon1989/Worlds/MainWorld/MainWorld_Layers/
# Place_saint-philippe_<slot>.layer) as Fit_saint_philippe_<slot>_<kit row>. `stand`/`use` find them by
# name in the running world, so this flow does not need the DebugWorld pad index (`layer` verb).
#
# PENDING steps name the entity their slot card is expected to fit. When the card lands, check its
# layer and fix the name here if the kit row differs; until then those lines report error/not found.
