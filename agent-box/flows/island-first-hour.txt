# Island first hour (#2935, the Friday go/no-go gate): a newcomer's first hour on Saint Philippe,
# real Everon (MainWorld), steps 1 to 10 of C:\LF\lead\weekend-everon.md "The first hour".
# The manual twin for the live 0grind smoke is docs/playtest/island-first-hour.md.
#
#   node agent-box/session.mjs up --mission island --clients 1 --roster 1 --profile full --wait
#   node agent-box/harness.mjs --client 1 flow island-first-hour
#   node agent-box/session.mjs down
#
# A fresh client profile is required: the rules quiz and form R-89 must be the first screens, and step 1
# checks the starting money. --roster 1 lets client 1 clock in as police (`--admin-client` is refused off
# the playtest mission).
#
# The flow judges itself (agent-box/flow-asserts.mjs). `step <id> <title> [pending #N]` opens a step and
# reads the player's state; any failed line in the step, or a failed `expect`, fails it. The run ends
# with a PASS/FAIL table and exits 1 when any step failed. A failed step does not stop the run.
#
# Entities are named in the fitted island layers (addons/LF_Everon1989/Worlds/MainWorld/MainWorld_Layers/
# Place_saint-philippe_<slot>.layer) as Fit_saint_philippe_<slot>_<kit row>. `stand`/`use` find them by
# name in the running world. A `use` whose named entity is missing fails (wrong_target:<what it hit>),
# never falls back to a nearby prop with the same action.
#
# Pending steps name the entity their slot card is expected to fit. When the card lands, check its
# layer and fix the name here if the kit row differs, then drop the `pending #N` from the step line.
