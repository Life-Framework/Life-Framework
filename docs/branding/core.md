# Brand brief: Life Framework (Core)

DRAFT for the maintainer's sign-off (#375). Agents write the Workshop kit, the website and
the docs from this page. Decision: `docs/decisions.md` 2026-11-09 "Two Workshop items, two
brands".

## Who it is for

Server owners who want a roleplay game mode, and pack authors who want to build a setting on
it. Players meet it only as the item their pack pulls in.

## What the page says

- Life Framework is an open-source roleplay framework for Arma Reforger.
- The core decides what the game can do: jobs, money, police, crime, vehicles, persistence.
  A pack decides what a server is: its map, names, prices and look.
- It is setting-neutral. It runs a modern or fictional pack as well as a period one.
- The page opens with "Looking to play?" and a pointer to Life Framework: Everon 1989.
- It links the host guide, the pack-author docs and the issue tracker, and states the licence
  (Workshop build APL, source on GitHub MIT).

## Voice

Plain, technical, calm. Short declarative sentences. Say what a system does and what it needs.
No period flavour, no place names, no story, no promises about dates or features.

## Names

| Where | Text |

## Art direction

Clean and modern. Neutral palette, the Life Framework logo, no period props, no vehicles of
a particular era, no place that a player would recognise as Everon. The preview shows the
framework, not a village: a calm diagram or an interface-free establishing shot of a generic
street. Gallery shots, when they exist, show tools and systems (a config, a placed sign), not
the flagship town.

## Not here

Anything from `everon-1989.md`: the 1989 premise, village names, period copy, period art. If a
sentence only makes sense in 1989, it belongs on the pack page.

## Status of the art

`docs/marketing/workshop/preview.jpg` still shows the village. It is a placeholder until neutral
art exists, and the maintainer signs the replacement off.
