# Release

The first public feature set. Every item uses 1989 places and base-game assets. The shared breach is [forced entry](../scopes/crime/forced-entry.md); the robberies are places that use it.

## Crime

| Scope | Ships as |
| --- | --- |
| [Forced entry](../scopes/crime/forced-entry.md) | Charge a configured door or container; it stays open until repaired |
| [Bank robbery](../scopes/crime/bank-robbery.md) | Vault breach, cash leaves in bags |
| [Jailbreak](../scopes/crime/jailbreak.md) | Jail door opens until repaired |
| [Hospital robbery](../scopes/crime/hospital-robbery.md) | Till plus a locked medicine cabinet |
| [Gas station robbery](../scopes/crime/gas-station-robbery.md) | Till at a fuel station |
| [Contraband](../scopes/crime/contraband.md) | Gather, process at a hideout, one convoy job |

## Police

| Scope | Ships as |
| --- | --- |
| [Jailing](../scopes/police/jailing.md) | Sentence at a placed jail, without requiring a vehicle escort |
| [Ranks](../scopes/police/ranks.md) | Rank ladder; duty kit is vanilla gear |

## Work and ownership

| Scope | Ships as |
| --- | --- |
| [Resources](../scopes/work/resources.md) | Legal gather and process chains on the playable world |
| [Civilian jobs](../scopes/work/civilian-jobs.md) | Taxi, fuel delivery, parcel delivery, levels |
| [Organizations](../scopes/ownership/organizations.md) | Persistent group, shared funds, bought upgrades |
| [Hideouts](../scopes/ownership/hideouts.md) | One owned building where processing and the convoy start |
| [Vehicles](../scopes/ownership/vehicles.md) | Buy, lock, and register base-game vehicles |

## Release bar

A new player can work a legal job, own a base-game vehicle, be jailed, and either rob a configured site or run contraband for an organization. Police can rank up and repair a breached door. No extra asset mod is required to play that session.

## Explicitly not in this cut

Private housing purchase, a general crafting bench, revive, police mission board, world events, aircraft, and any new weapon or vehicle mesh. Those are [after release](after-release.md).
