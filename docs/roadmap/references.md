# Reference projects

Public Reforger projects to look at for ideas before building a system. Read the
licence first: MIT code, and code the author has given us permission to use, can be ported with
the `THIRD_PARTY.md` header; APL-ND, APL-SA without the author's permission and
GPL-2.0 code is ideas only. Never copy text or code from those. Also see [sources.md](sources.md) for
what we reuse from this repo and the base game.

| Project | Licence | What it is |
| --- | --- | --- |
| [Reforger Mapper](https://github.com/benjibossk/mappingenfusiontest) | MIT | Map-design web tool with a local bridge and Workbench plugins; `docs/FINDINGS.md` lists Workbench scripting traps |
| [reforge-mcp](https://github.com/WannabeCoderLuc/reforge-mcp) | MIT | Workbench MCP server (rewrite of `enfusion-mcp-bk`); API lookup built from the installed game's paks |
| [DarcMods](https://github.com/mokdevel/DarcMods) | APL-ND | Missions and convoys mixing AI driving with virtual movement; mission state machine |
| [Kexanone mods](https://github.com/Kexanone/ArmaReforgerMods) | APL-SA | Cleanup queue, vehicle deletion guard, scenario jobs |
| [TrainWreckLooting](https://github.com/TrainWreckers/TrainWreckLooting) | none stated; **permission granted by the author** | Container loot: tagged containers, loot tables, refill (archived, no longer compiles as is). Can be ported with attribution |
| [NIRE mods](https://github.com/Typ2011/NIRE-Mods) | GPL-2.0 | Rules quiz, crate cargo, ACE-style medical UI |
