# Development Roadmap

> Source: https://life-framework.org/roadmap (scraped). This is the project's
> living roadmap for building "the most comprehensive framework for Arma
> Reforger". It keeps the team organized and ensures contributions don't get
> lost. Contributions are coordinated via Discord: https://discord.gg/MjMexJteqz

The roadmap is a *starting point*. As we develop and test, new ideas emerge to
enhance gameplay and address community needs. Anyone who can help with an item
should jump in on Discord to be assigned.

## Development Values

- **Quality First** — Well-tested, reliable code
- **Open Collaboration** — Transparent development
- **Documentation** — Clear guides & comments
- **Modularity** — Flexible, reusable systems
- **Performance** — Optimized & scalable
- **Community Input** — Player-driven evolution

## Phase 3 — Law Enforcement (6 items, 0% complete)

> Creating comprehensive law enforcement systems and player-run organizations
> for social gameplay.

| Item | Status | Description |
| --- | --- | --- |
| Fine & Ticket System | Planned | Interface for issuing fines and tickets; integrate with crime system and player records |
| Police Department Infrastructure | Planned | Build police station; rank progression system from patrol officer to detective |
| Arrest & Detention System | Planned | Arrest mechanics with handcuffs and tasers; transport to jail and prison where players serve time |
| Crime Tracking System | Planned | Crime list with severity levels, penalties and punishment; crime reporting via interface, chat, or hotline |
