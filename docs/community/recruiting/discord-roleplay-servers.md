# Blurb for other communities (draft, not posted)

Status: drafted. Not posted. For other Reforger, life and roleplay Discords. **Each server's own rules
decide**: ask a mod before posting, post only in the channel they name, and post as the maintainer.
Nothing here is for DMs or cold invites. If a mod says no, say thanks and mark it declined in
[the tracker](../outreach/tracker.md).

**Attach one picture:** `town-1-vista-dusk.jpg` (see [the picture table](README.md#pictures)).

**Link:** `https://life-framework.org/join/roleplay-servers`. Add that source to
`website/content/outreach-sources.json` before the first post ([README](README.md#link-tags)), and
one tracker row per community.

## Ask the mods (send first)

```
Hi. I'm the maintainer of Life Framework, an open-source life/RP framework for Arma Reforger. It's an alpha and we're looking for playtesters. Would a short post with one picture and one link be welcome here, and in which channel? Happy to follow whatever format you prefer.
```

## The blurb (about 550 characters)

```
Life Framework is an open-source life/RP framework for Arma Reforger, in alpha. There's a small 1989 Everon town to play in (bank, store, police, medics, payphones) and a playtest every week. The server, "Life Framework | Everon 1989 (Alpha)", is invite-only: ask in our Discord and a staff member sends the password. You can also run your own; the core and the 1989 pack are both on the Workshop. Built mostly by AI agents under the maintainer's direction; source is MIT on GitHub. Expect bugs; reports welcome. https://life-framework.org/join/roleplay-servers
```
