# Recruiting drafts

Drafts for getting more playtesters and more contributors. **Nothing here has been posted.**
The maintainer posts, as themselves, after reading each community's own rules and asking
its mods where the rules ask for that. Agents never post, and never use a user account to
do it. The rules every post follows, the order of steps and the tracking are in
[the outreach kit](../outreach/README.md); the honest replies to common questions are in
[its FAQ](../outreach/faq.md).

## Facts every draft uses

Check these still hold on the day you post, then fix the drafts and the FAQ together.

- Server: **Life Framework | Everon 1989 (Alpha)**. Invite-only. The password is given out on our
  Discord and is never written in a post or a doc ([alpha.md](../alpha.md)).
- Playtest sessions are weekly and announced on Discord. The save can be wiped with 24 hours' notice.
- Workshop: the core <https://reforger.armaplatform.com/workshop/4550A2B656E1B569> and the 1989
  pack <https://reforger.armaplatform.com/workshop/B1E84D5687E11724>. A server needs both. Open both
  pages signed out before posting: the owner install guide and issue #1711 recorded the pack as not
  yet on the Workshop at the last dry run, and
  [the outreach FAQ](../outreach/faq.md) still says there is no Workshop item.
- Source: MIT on GitHub. The Workshop build is under the Arma Public License.
- Built mostly by AI agents under the maintainer's direction; every change is a public pull request.
- Tone: honest alpha, no hype, no dates, no promises ([discord.md](../discord.md), "Stance").
