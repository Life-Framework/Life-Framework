# Outreach: the official Arma Reforger Discord

Status: not asked

## Community

The largest Reforger community Discord, run by or with Bohemia Interactive.
Players, modders and server owners mix there. A life framework is on topic for
its modding and server areas, but a mod post is advertising, so it needs
permission.

## Rules

UNVERIFIED. We could not read this server's rules from outside it: no public
copy turned up, and Bohemia's support pages say rule enforcement on community
servers is each server admin's job. Before asking, read the rules channel and
check these three things:

- Does it allow advertising a mod or community, and in which channel only?
- Does it want a mod's Workshop link, not a GitHub or website link? (Our test
  build is not on the Workshop yet, see the [FAQ](faq.md).)
- Is there a mod showcase or "creators" area that needs a role or an approval?

If the answers are no, do not post. Ask the mods whether there is somewhere that
fits, and record "declined" in the [tracker](tracker.md).

## Where

A modding showcase or community-projects channel if one exists. Not a general
or support channel. UNVERIFIED which channel fits; the rules channel will say.

## Ask the mods

Send through the server's mod-mail or ticket, not a DM to one person.

```
Hi. I'm the maintainer of Life Framework, an open-source life and roleplay
framework for Arma Reforger (MIT, on GitHub). It is an early test build, not a
release, and it isn't on the Workshop yet.

Would you be happy for me to post a short introduction in <channel>? I'd read
the rules first and post once, with two screenshots and one link. If a
different channel fits better, or it isn't welcome here, no problem.
```

## Post

About 900 characters. Discord renders it as plain text with a link preview.

```
Life Framework: an open-source life and roleplay framework for Arma Reforger, early test build.

We're building the framework and a 1989 Everon server to prove it. Right now one small test town is playable: a bank, a store, a car lot, police, medics, payphones, a fence and a few crimes. Most of it has had few players.

Things happen in the world (a clerk, a counter, a payphone) instead of menus, and the systems are kept apart from the 1989 setting so another setting could use the same core.

For honesty: it's built mostly by AI agents under my direction. I merge every change, and each one is a public pull request that has to pass checks. There's no release date, and it isn't on the Workshop yet.

If you'd like to try the test town and tell us what breaks: https://life-framework.org/join/arma-reforger-discord
```
