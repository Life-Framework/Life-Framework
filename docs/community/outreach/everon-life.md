# Outreach: the Everon Life community

Status: not asked

## Community

Everon Life is the open-source life and roleplay framework for Reforger that
our code started from (MIT; `THIRD_PARTY.md`, `docs/everonlife-forks.md`). Its
Workshop page lists a GitHub organisation (github.com/EveronLife) and a Discord
(discord.gg/ExamVwWfVK). UNVERIFIED: the invite came from a Workshop page we
read in a search result; check that it still works before using it. An older
page listed a different invite (discord.gg/EveronLife).

Several servers and forks build on it, and some forks have their own licences,
so who owns a given channel is not always clear. Ask in the main server, not a
fork's.

## Rules

UNVERIFIED. We could not read the server's rules from outside it. Read them
first. Expect that promoting another life framework to their members needs
permission, and that a mod may say no. That is a fair answer; accept it.

## Where

The channel for other projects or general chat if the rules allow it, otherwise
only what the mods say. Do not post in support channels.

## Ask the mods

Lead with credit. Send through mod-mail or a ticket.

```
Hi. I'm the maintainer of Life Framework, an open-source life and roleplay
framework for Arma Reforger. Our code started from EveronLife (MIT) and we
credit it in the repo (THIRD_PARTY.md). We're a separate project: our class
prefix is LF_, so both mods can be installed on one server without colliding.

Would you be happy for me to post a short note in <channel> saying so, with one
link? If you'd rather I didn't, no problem, and thank you for the project we
learned from.
```

## Post

About 700 characters.

```
Hi all. I'm the maintainer of Life Framework, an open-source life and roleplay framework for Arma Reforger, early test build.

Our code started from EveronLife and we credit it in the repo. We're a separate project, not a replacement: world-based interactions (a clerk, a counter, a payphone) instead of menus, systems kept apart from the 1989 Everon setting, and an in-game test suite. The LF_ prefix means both can be installed on one server; we don't provide a bridge.

It's built mostly by AI agents under my direction, every change is a public pull request, and there's no release date. One small test town is playable now.

If you'd like to try it or just see what's there: https://life-framework.org/join/everon-life
```

## After

- "Why not contribute to Everon Life instead?" See "Why not just use Everon Life?" in the [FAQ](faq.md). Do not argue; say the architecture goals differ and thank them.
- A licence question about our use of their code: answer from `THIRD_PARTY.md` and `docs/everonlife-forks.md` and send it to the maintainer. It may be legal; the bot hands it to a human ([bot playbook](../bot-playbook.md)).
- Do not recruit their members. If someone asks to move, point them to the FAQ and stop there.
