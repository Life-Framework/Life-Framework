# Feedback triage after a playtest session

A moderator runs this after each playtest session. The feedback channel holds the raw reports. This page turns them into GitHub issues that the team can track.

## Steps

1. **Read the feedback channel.** Go through every post from the session. Skip repeats of a report already made in the same session.
2. **Make one issue per problem or idea.** Use the Playtest form, `.github/ISSUE_TEMPLATE/playtest.yml`. It adds the `playtest` label and asks who you were, what you did, and what you saw. Copy the fields from the Discord post. Keep the player's words where you can.
3. **Link the issues under the announcement.** Add the new issue links under the session announcement on Discord, so players can see that their report became an issue.
4. **Run the log side.** `host triage` (planned) goes through the session's server log for the same session. Match what the log shows to the reports. Add anything the log shows that no player reported.

## Notes

- A report is read by a person. Filing an issue does not promise a fix. Say so if a player asks.
- Feedback that is not about the game (account help, server access) goes to the [support page](support.md), not to an issue.
- The [moderator guide](moderator-guide.md) covers the rest of a moderator's work.
