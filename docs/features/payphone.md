# Payphone (#247)

- ✅ `LF_Payphone` (prefab `Prefabs/Comms/LF_Payphone.et`, the base-game phone booth): one action per preset: report a crime, an emergency or someone suspicious (police), ring for a doctor (medic), ring for a cab (taxi; mechanic waits for a mechanic job). The coin comes from carried cash (`m_iPayphoneCost` in `LF_ServiceCalls.conf`), per-player and per-phone cooldowns apply, and nothing is charged when nobody is on duty. The call is `LF_OnServiceCall` on the bus; `LF_ServiceCallDispatch` turns a police call into a radio line to on-duty officers with the phone's place (`LF_Dispatch.Receive`), and the dispatch log shows it. Coin and dial-tone sounds play from the booth. Not done: free text, handset animation (the booth has no handset mesh). Placed in DebugWorld at the square, the fuel station, the hospital and the police station (#254), with a police dispatch board (`Prefabs/Comms/LF_DispatchBoard_Police.et`) beside the wanted board.

- ✅ **Fixed (#147):** a player or payphone that had never called read as having called at time 0 (`map.Find` leaves 0 in the out value when the key is missing), so every call in a server's first 60 s was refused with the cooldown. `LF_Payphone.UseAt` now treats a missing entry as never used; `comms/payphone` covers a first call at second 5.

- ✅ **A missed dial is cooled down (#2405, life review 2026-11-17).** A call nobody on duty answers took no coin and stamped neither cooldown, so a player could redial every second (each dial built a call row, a bus event and log lines). `LF_Payphone.UseAt` now stamps a per-player-and-service miss time (`MissKey`, `LF_EPayphoneResult.MISSED_COOLDOWN`, the player cooldown's length, toast `LF-Payphone_Cooldown`); the check runs before the route lookup. It is per service so a missed medic call never blocks an emergency call to the police. Test `comms/payphone`.

- ✅ **A carried radio set calls from anywhere (#3155).** `LF_HandsetCallAction` on a radio item (pack prefab `LF_Everon1989/Prefabs/Items/Comms/LF_HandsetRadio.et`, the vanilla R148 retuned to 46.0 MHz and up so it never reaches the police or medic duty frequencies; $250 at the general store) places the payphone's call from where the carrier stands: one action each for a cab, a doctor and the police. `LF_HandsetCall.CallAt` checks the radio is in the caller's inventory, a per-player-and-service cooldown (`m_iPlayerCooldownSeconds`), the route (nobody on duty takes no fee), then takes the fee (`m_iFee` on the action, 5) from carried cash only when the whole fee is there, and calls `LF_ServiceCalls.Place` with the caller's position, so the board, pager and police dispatch see it like a payphone call. Server only; the client sends which action it picked. Test `comms/handset-call`.
