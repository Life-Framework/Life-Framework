### `LF_WheatField` and `LF_WheatFieldView` — `Feature/Harvest/LF_WheatField.c`, `LF_WheatFieldView.c` (#3287, 2026-11-19)
- 🧪 A placed wheat field draws itself: `Prefabs/Harvest/LF_WheatField.et` (`LF_WheatField`, box `m_fSizeX` x `m_fSizeZ`, default 60 x 40 m = 260 cells, centred on the entity, yaw ignored) keeps the `LF_WheatGrid` cut bitset and, on every machine except a dedicated server, one local `StaticModelEntity` patch per standing cell (`SpawnEntityPrefabLocal`, never replicated). `CutCells(cells)` marks the bitset and swaps each cut patch for stubble (a repeat or out-of-range cell is skipped, the return is the newly cut count); `Regrow()` clears the bitset and stands every patch again. The patch, stubble and cell size come from `Configs/Harvest/LF_WheatFields.conf` (vanilla stand-ins `c_arrhenatherum_elatius_01` and `c_fallen_leaves_01` until H5a). Every change logs on `[LFDebug:Harvest]`. Nothing replicates yet (#3288) and no reaper calls it (#3289). DebugWorld grid cell `slice-3287` holds a 45 x 21 m field. Test: `harvest/wheat-field-cut` (WORLD).

### `LF_ImplementHitch` and `LF_ImplementComponent` — `Feature/Harvest/LF_ImplementHitch.c`, `LF_ImplementComponent.c` (#3284, 2026-11-19)
- 🧪 A reaper hitches behind a UAZ469 or a Z7211. Server `LF_ImplementHitch.Hitch(vehicle, out reason)` spawns `Prefabs/Harvest/LF_Reaper_01.et` with the vehicle as its parent (`EntitySpawnParams.Parent`, the vanilla weapon-rack way) at the local offset of the vehicle's row in `Configs/Harvest/LF_Hitches.conf`; a row matches the vehicle's prefab or any ancestor, so every UAZ469 variant uses the `UAZ469_base` row. Neither mesh has a hitch pivot: the UAZ469 offset (0, 0, -3.4) sits behind its measured rear bound (-1.87 m); the Z7211 row (0, 0, -3) is an estimate, since the Rally DLC tractor does not load on the test server. The reaper has a mesh (vanilla `CultivatorWreck_01` until H5b), a `Hierarchy` and an `RplComponent`, and no physics body, so it never drags or flips the vehicle; the hierarchy replicates, so other players and late joiners get it under the same vehicle. Refusals (not the server, not on the hitch list, already towing, a bad prefab) set the reason and log on `[LFDebug:Harvest]`. `Unhitch` deletes the reaper; `FindHitched` finds it on any machine. `LF_ImplementComponent` holds the bar width and the replicated hopper kg (`SetHopperKg`, for the cut tick #3289) and logs `implement present` / `implement follows` (every 10 m the vehicle moves) on every machine, with `behind true|false`. No player action hitches yet (the implement rack is H8, #3295); nothing is persisted. Test: `harvest/implement-hitch` (WORLD).
