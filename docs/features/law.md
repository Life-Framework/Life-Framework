# Law book

- ✅ Law-book codes (#4202): every `LF_CrimeEntry` in the crime catalog (`Feature/Crime/LF_CrimeCatalog.c`) carries a law-book section (`m_eLawSection`: criminal, road, narcotics, weapons), a stacking group (`m_sStackGroup`) and a jail-only flag (`m_bJailOnly`). New and unchanged rows default to criminal, no group, finable, so no save or shipped `.conf` changes. The owner's `crime` section sets them per code with `section`, `stackGroup` and `jailOnly`; a bad section is refused and logged `[LFDebug:Law]`. `LF_LawCodeRules` (`Feature/Law/`) totals a charge list by rule: two codes in one group stack to the higher, codes in different groups (or with no group) add, a jail-only code refuses a fine but its time still counts. Server logic only, no UI yet; the pack's codes come with L2 and the charge sheet with L3. Test `law/code-stacking`.
