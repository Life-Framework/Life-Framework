# Record a clip for a report

A clip is a video of what happened on screen. Staff use it with a report or an appeal. The server keeps its own incident log and that covers most cases, so a clip is a backup, not a requirement.

## Report first

Type `/report` in chat as soon as the event ends. It flags your recent incidents from the last 10 minutes, and staff see them first in the Game Master incident list. You can send it once every 2 minutes. The game answers with one short message:

- "Staff were told about your recent incidents." The report went through.
- "Nothing of yours to report from the last few minutes." Nothing was logged for you, so describe the event in your note.
- A cooldown message. Wait 2 minutes and send it again.

`/report` does not give you an incident number. Staff find the incidents from the log, so give them the names and the time instead (see below).

## Record the clip

1. Turn on the clip stamp before you start recording (see below).
2. Use any screen recorder. Record the whole screen, not a crop, so the HUD and chat show.
3. Start the recording a few seconds before the event.
4. Stop the recording after the event ends, then send `/report`.

## The clip stamp

The stamp is a small tag in the top left corner. It shows the server name, the last six characters of your player ID, and the server's date and time in UTC, for example `LF  /  A1B2C3  /  2026-11-14 21:40:07 UTC`. The time comes from the same clock as the incident log, so staff can match your clip to a log row. It is not the in-game clock.

- It starts off. Press **F9** (keyboard) or **RB + View** together (gamepad) to show it, and press the key again to hide it. The key is listed under Controls.
- It appears a moment after you press the key, because the server has to answer first. The seconds keep moving on your screen between answers.
- The server name is set by the server owner. The default is `LF`.
- If the owner has turned the stamp off, the key shows a short message and nothing appears. Write the time down instead.

## What to write with the clip

Send one short message with the clip:

- The server name.
- Your character name and the names of the other players involved.
- The time the event started. If the stamp was on, read it off the clip. If not, write the time with your time zone, for example `14 Nov 21:40 CET`.
- What happened, in order, in one or two lines.

## Record on each platform

- **PC:** Press Win+Alt+R to start and stop the Windows Game Bar recorder. Any other recorder works too.
- **Xbox:** Press the Share button to capture a clip.
- **PlayStation 4:** Press the Share button to capture a clip.
- **PlayStation 5:** Press the Create button to capture a clip.

## Send it

Send the clip and your note to staff on [Discord](https://discord.gg/MjMexJteqz). Do not post another player's clip in a public channel. Keep the link to your clip up for at least a week, so staff can open it if the report is read later.

## For an appeal

Use the same clip and note, and follow the [appeals guide](community/appeals.md). Say what you think went wrong, and say what you want staff to check.
