# Record a clip

A clip is a video of what happened on screen. Staff use clips with reports and appeals. The server keeps its own incident log, so a clip backs up your report. It does not replace `/report`.

## The game has no on-screen clock

The game does not show an in-game time or a server stamp on screen yet. Write the time down before you start recording, and use the real time with your time zone. The in-game clock is game time, not real time, and the incident log uses real time. A follow-up issue will add an on-screen stamp.

## Before you record

1. Turn on your recorder. Use any screen recorder. Record the whole screen, not a crop, so the HUD and chat show.
2. Start the clip a few seconds before the event.
3. Type `/report` in chat as soon as the event ends. It flags your recent incidents from the last 10 minutes. You can send it once every 2 minutes.

## What to write down

Write these in one short message with the clip:

- The server name.
- Your character name and the names of the other players involved.
- The real time the event started, with your time zone, for example `14 Nov 21:40 CET`.
- What happened, in order, in one or two lines.
- The incident number, if you have one.

## How to record on each platform

- **PC:** Press Win+Alt+R to start and stop the Windows Game Bar recorder. Any other recorder works too.
- **Xbox:** Press the Share button to capture a clip.
- **PlayStation 4:** Press the Share button to capture a clip.
- **PlayStation 5:** Press the Create button to capture a clip.

## Sending the clip

Send the clip and your note to staff on [Discord](https://discord.gg/MjMexJteqz). Do not post another player's clip in a public channel.

## For an appeal

Use the same clip and note. Say what you think went wrong, and say what you want staff to check.
