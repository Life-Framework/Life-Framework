## What this run did not prove

- Three clients: a 3-client session joined 2 of 3 within 240 s on this PC (client 1 also exited at
  launch once without a log). The journey harness is written for two clients, so the run is A and B.
- Police B loop (clock in, board, dispatch, ticket, arrest, jail) and civilian C (hideout, stash,
  contraband) are not journey steps. The `police` fixture is debug-menu only and skipped on the
  playtest mission, so B stayed civilian and only received the till alert path checks that fit.
  Jail and hideout persistence are covered by the e2e above, not driven by a player client.
- Restart check covers cash, bank, org and job; rank, stash and vehicle-in-garage are not in the
  restart judge.
- lf-testbox was DOWN (no ssh); nothing was left open there that this PC could release. Nothing
  stale was left on this PC (session records `gone`, slot free).

## Verdict

Not ready to call M1 proven. The civilian loop (arrival, job, ATM, shop, car, give, till robbery,
org, garage) and the restart survive on a dedicated server. The police and org-C loops need
journey steps that run on the playtest mission without debug fixtures, and a 3-client run.
