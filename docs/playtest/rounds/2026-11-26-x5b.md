## Tooling notes

1. **`checkpoint <hour>` needs its file in the server profile.** On a plain `session up` it logs `no file in $profile:LifeFramework (seed agent-box/checkpoints/hour-5.json)` and changes nothing; I copied `hour-5.json` into `<session>/server/profile/LifeFramework/` by hand. Seeding from `session up` (`--seed`) or by default would remove the step.
2. **`truck-check-proof` has two stale checks.** It expects the first lot row to be the Ural at $9,500 (the first row is now the Cargo truck at $12,000, so "the truck's $9500 left the bank" fails although the purchase and the money line are right), and it expects the licence desk to sell the driving licence (the checkpoint already holds `DRIVING_LICENCE`, so "the driving licence is bought through the licence desk's server entry" fails). Run on a checkpoint character, or update the proof to read the row price.
3. **`hold weapon` right after a swing answers `drew ... 0`** (not equipped); after `hold none` and a wait of about 6 s it answers `1`. A proof should wait before relying on the draw.
4. **`state` can answer `no_session` for a second after an ATM run** (three tries in `truck-check-proof` before it read).
