**Commit played:** `origin/main` at `eaed99840` (PR #4871, booking desk, merged), plus PRs #4872 (casualty outfits and bed delivery) and #4873 (tools drawn as the weapon
count as held) merged into the worktree locally at `b26e126d4` and `68b66e327`, because neither had merged when the session started (both have merged since, so the ship branch carries only this report). Card #4180, branch `ws/playtest-r6`.
Earlier rounds: [round 5](2026-11-24-round5.md), [X-5](2026-11-26-x5.md), [X-5 leftovers](2026-11-26-x5b.md). This round replays their open rows and does not repeat
what passed there (the gang founding and gang radio of X-5 leftovers are not replayed: nothing in that code moved).

**Setup:** one session, `--mission island --clients 2 --profile full --sound --hold 20`, all eleven `agent-box/checkpoints/hour-N.json` passed with `--seed`
(boot 82 s, 15:39 to 16:26 local, closed with `session down` straight after the last row; nobody queued, so the 20 minute hold was never enforced).
Client 1 is a fresh "Ada Lovelace"; client 2 was the second officer and suspect in the police proofs.

**Method limits.**
- The harness cannot walk or drive. Travel is `stand <Entity>`; the proofs reset the player, so a row that starts from a proof starts from its fixture, not from a checkpoint.
  I did not use `checkpoint <hour>`: the arcs were each played from a fresh or proof-reset character, which is what a first run through that arc needs. (The seeded files were
  accepted by `session up`; `[LFDebug:Checkpoint]` was never called, so the seed path is unproven this round.)
- Nothing was heard. Sound rows are server and client log lines only.
- A harness client runs at about 3 fps, so a dialogue line takes 13 to 25 s to play before the reply row shows. Timings below are session seconds; real-player time is my estimate.
- Pictures: 10 client captures converted to JPEG before `session down`, in `website/public/docs-images/playtest-2026-11-24-r6/` (`img/` below). Two were read.
