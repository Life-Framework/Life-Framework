2. `levelset MINER <n>` then an immediate `capture ui` catches the level-up card (it fades in seconds): `levelupcard state` reads `card=shown` at that moment.
3. `booking-desk-proof` run a second time in a session that had done other work failed 1b (the cuff state read came before the client caught up; the server log showed `restrained` a second later) and every later step. After `session restart` it passed 23 of 23. A flake of the proof's timing in a loaded session, not a game result.
