## Re-running

```
tools\cli session up --mission island --profile full --hold 20 --wait
node agent-box/session.mjs ui-sweep rich          # checkpoint 10; or `starter` for a fresh character
node agent-box/session.mjs ui-sweep rich shop_    # only the shops; `!shop_` for everything else
tools\cli session down
```

Data lands in `tmp/ui-sweep/<phase>.json`, pictures are named `sweep_<phase>_<site>`. Static: `node tools/validation/validate-dialogue-refs.mjs`; in game `tools\cli test --no-build --only LF_Test_EveronShopNames`.
