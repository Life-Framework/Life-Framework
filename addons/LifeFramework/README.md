## About (Future Vision)

Life Framework provides the foundational systems for creating Life-style gameplay experiences in Arma Reforger. Set in 1989 to maximize compatibility with native Reforger assets, this framework gives you everything you need to build your own unique Life server.


## Development

This mod is designed to be extended. You can:

- Create addon mods that depend on Life Framework
- Override and extend core systems
- Add new jobs, items, and interactions
- Customize the economy and progression

See the main [documentation](../../docs/README.md) for development guides.

## Installation

### For Players
1. Subscribe to Life Framework on the Reforger Workshop
2. Join a server running Life Framework

### For Server Owners
See the [server setup guide](../../server/README.md) for detailed instructions.

### For Developers
1. Clone this repository
2. Open `addons/LifeFramework` in Arma Reforger Tools (Workbench)
